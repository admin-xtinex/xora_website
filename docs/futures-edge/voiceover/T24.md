# T24 Meet XORA: voiceover script

Lesson `T24` · 43 lines · about 687 words · film 5:19.0 as written

**Tone:** Warm, clear and patient, like a good teacher explaining to a friend. Brighter on examples and 'try it'; slower and firmer on risks and warnings.

Record each line as its own file, `content/futures-edge/T24/voice/NN.mp3`, using the **Say** text. The **Slot** is the time from this line to the next one in the film as written; a line may run longer (the build slows that scene to fit), but a line much longer than its slot stretches the animation, so keep the pace natural rather than rushed. "Firmer, slower" marks risk and warning lines. Malayalam is the on-screen subtitle, for reference only.

See [README.md](README.md) for the voice, file format and how to build.

# Welcome to XORA Futures Edge: voiceover script

Lesson `V00` · 37 lines · about 304 words · film 2:00.0 as written · **already recorded** (voice/ exists; re-record only to change the voice)

**Tone:** Welcoming and upbeat, like greeting a new student. Smile in the voice.

Record each line as its own file, `content/futures-edge/V00/voice/NN.mp3`, using the **Say** text. The **Slot** is the time from this line to the next one in the film as written; a line may run longer (the build slows that scene to fit), but a line much longer than its slot stretches the animation, so keep the pace natural rather than rushed. "Firmer, slower" marks risk and warning lines. Malayalam is the on-screen subtitle, for reference only.

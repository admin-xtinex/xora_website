# CPB Checkpoint B: voiceover script

Lesson `CPB` · 39 lines · about 582 words · film 4:19.0 as written

**Tone:** Encouraging quiz host. After each question, a natural pause; read the answer with a little satisfaction, never as a test.

Record each line as its own file, `content/futures-edge/CPB/voice/NN.mp3`, using the **Say** text. The **Slot** is the time from this line to the next one in the film as written; a line may run longer (the build slows that scene to fit), but a line much longer than its slot stretches the animation, so keep the pace natural rather than rushed. "Firmer, slower" marks risk and warning lines. Malayalam is the on-screen subtitle, for reference only.

See [README.md](README.md) for the voice, file format and how to build.
